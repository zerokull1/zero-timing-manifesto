# Бортсамописец дампов (`flight_recorder`)

Высокоскоростной модуль сброса перехваченных аномальных кадров и телеметрии на диск через прямые системные вызовы `io_uring` (без сторонних зависимостей).

## Особенности
* Выровненные по кэш-линии 256-байтные слоты (`dump_slot_t`) с отметкой времени `TSC` и вердиктом.
* Проверка авторского заголовка `ZEROMANI` при чтении и верификации дампа `.zcap`.
