# Подключаемые навесные модули (`modules/`)

Независимые динамические модули (`.so`), подключаемые поверх замороженного базового ядра через единый заголовок `module_abi.h` с обязательной верификацией авторской подписи `ZEROMANI` (`0x494E414D4F52455A`).

## Состав линейки
1. **`entropy_shaper/` (ID=3):** Адаптивное сглаживание энтропии Шеннона, выравнивание размеров кадров и генерация браузерного джиттера `IAT` (~32.45 млн кадров/с на 1 ядре).
2. **`deception_tarpit/` (ID=1):** Липкая ловушка-тарпит без хранения состояний — мгновенная генерация ответных кадров `TCP ACK` с нулевым окном (`Window = 0`) для заморозки сканеров и ИИ-ботов (~126.34 млн ответов/с на 1 ядре).
3. **`xdp_live_daemon/` (ID=2):** Автономный сторож карты ядра `XDP` — загрузка подписанных SWAR-правил, горячее обновление `BPF_MAP` и инспекция кадров без перезапуска сетевого интерфейса.
